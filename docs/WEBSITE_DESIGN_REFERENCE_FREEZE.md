## KORA Reach design rules
- English-first international landing page, Apple-class editorial hierarchy and legibility.
- Mac app style, not a developer documentation site pasted into a hero.
- Five concepts must differ materially in spatial composition, hero storytelling, photo treatment, section arrangement and typography, not merely palette.
- Main visual assets must be **PNG or JPEG raster images**. Do not generate any SVG illustrations.
- Real product screenshots must be labeled real; generated compositing or illustrative imagery must not be represented as live functionality.
- Display only observed/released capabilities as available; continuous in-chat live screen, full GUI semantic automation, broader safety gates remain in validation.
- CTA for free OSS and separately labeled Personal Pro hypothesis. Do not imply that a paid service or one-click installer is live.
- Preserve layout references without copying licensed images or webpage source into public release.
- Marketing site is optional distribution; OSS README remains a first-class product landing surface.
