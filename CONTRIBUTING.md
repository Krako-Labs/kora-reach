# Contributing

KORA Reach is deliberately small.

Before adding a feature, show that it improves at least one of these:

- fewer unnecessary frontier escalations;
- safer or more reliable local execution;
- easier installation;
- a stronger end-to-end demo;
- measurable user demand.

For v0.x, open an issue before large architecture, plugin systems, GUIs, hosted backends, or provider matrices.

Development:

    npm test
    npm run check

Use Node.js 22.12 or newer. Keep filesystem and process effects scoped to the selected workspace.
